# ワークシート：神経データを流して TCP/IP を確かめる

対象：学部2〜3年（ネットワークの基礎を学んでいる学生）、高校教科「情報」の教員を目指す学生
所要：90分×2回　　環境：Python 3.10 以上、`pip install -r requirements.txt`
すべての実験は自分の計算機の中（127.0.0.1）だけで行います。他人のネットワークに負荷をかけてはいけません。

## 0. 実行する前に予想を書く

1. TCP と UDP では、どちらが「速い」と思いますか。何をもって速いとするかも書いてください。
2. 受信側の解析が、データの届く速さに追いつかなくなったら、TCP と UDP ではそれぞれ何が起きるでしょうか。

## E1　必要な帯域を計算する

データ量 ＝ チャネル数 × 標本化周波数 × 1サンプルのバイト数 × 秒

- 問1　1,020 チャネル、20 kHz、16 bit（2バイト）のとき、1秒と1時間のデータ量、ビット毎秒を求めなさい。
- 問2　問1の1時間分を、100 Mbps と 1 Gbps の回線で送ると何分かかりますか（実効効率 94% とする）。
- 問3　ある研究室では、1時間あたり約130 GB の計測データの転送に1時間以上かかっていました。原因は建物の壁の中にあった 100 Mbps の配線で、交換後は約10分になったと報告されています。10分で送るのに必要な速度を計算し、1 Gbps の回線で説明できるかを答えなさい。説明できない場合、何を確かめる必要がありますか。
- 確認：`python -m nslab.experiments E1`

## E2　TCP はメッセージではなくバイト列を届ける

`python -m nslab.experiments E2` を実行し、`results/fig_E2_recv_sizes.png` を見てください。

- 問4　受信側が追いついているときと、ときどき遅れるときで、1回の `recv()` が返すバイト数はどう変わりましたか。
- 問5　「1回の `recv()` で1メッセージが届く」と仮定したプログラムは、どちらの条件で壊れますか。送信側の書き方を変えずに壊れるのはなぜですか。
- 問6　`nslab/framing.py` の `recv_exact()` と、ヘッダの `payload_len` を読み、長さを先に送る理由を説明しなさい。
- 発展　長さの代わりに区切り文字でメッセージを区切る方式の、長所と短所を挙げなさい。

- 問7　送信する量を増やしたとき、TCP と UDP のアプリケーション・ペイロード実効スループット（goodput）と欠落率はどう変わりましたか。UDPの最終断片が短いことも踏まえて解釈してください。
- 問8　この実験の UDP の欠落は、どこで起きたと考えられますか。ネットワークの中でしょうか、受信プログラムの処理でしょうか。根拠を挙げなさい。

## E4　受信側が遅いとき

`python -m nslab.experiments E4`（10 ms 分のデータの処理に 12 ms かかる設定）

- 問9　TCP では何も失われないのに、遅延が増え続けました。送信側のキューの図と合わせて、何が起きているかを説明しなさい（キーワード：受信バッファ、ウィンドウ、フロー制御）。
- 問10　UDP では何が起きましたか。計測データを実時間で解析する場合、どちらの振る舞いが望ましいでしょうか。条件を示して答えなさい。

## E5　欠落は波形をどう変えるか

`python -m nslab.experiments E5`

- 問11　何 % のサンプルが欠け、スパイクの検出数はどう変わりましたか。欠測部分をゼロで埋めたときの偽の立ち上がりを除くため、前後2サンプルとも受信済みであることを確認します。
- 問12　欠けた区間を補間して埋めるべきでしょうか、解析から除くべきでしょうか。それぞれの危険を挙げなさい。

## E6　待てる時間で、欠落への対処は変わる

`python -m nslab.deadline`（片道20 msの遅延と10 %の欠落を、アプリケーションの中継で模擬）

- 問13　予想：期限が25 ms、75 ms、400 msのとき、「何もしない（連番で欠落位置だけ知る）」「XORパリティ（4個に1個）」「再送（NACK）」のそれぞれで、何 % が届くでしょうか。測る前に表に書きなさい。
- 問14　独立な欠落と連続した欠落とで、パリティの効き方はどう違いましたか。4個に1個のパリティが1つのグループで何個までの欠落を直せるかから説明しなさい。
- 問15　再送で全部が届くまでに、往復の遅延の何倍の時間がかかりましたか。連続した欠落でさらに長くかかった理由を、受信側が欠落に気づく時刻から考えなさい。
- 問16　閉ループ刺激のように数十 ms で判断する処理と、数十分の記録をまとめて解析する処理とでは、どの方式を選ぶべきでしょうか。帯域の増加分も含めて答えなさい。

## まとめ

「TCP は低遅延」「UDP は高速」という言い方が、そのままでは成り立たない例を、自分の測定値から一つずつ挙げなさい。測定条件（OS、Python のバージョン、CPU、localhost であること）も必ず書いてください。
